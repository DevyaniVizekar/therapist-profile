# Dr. Maya Reynolds — Internship Assignment

A responsive Next.js + Tailwind CSS recreation/redesign of the Conejo Valley Family Counseling homepage, rewritten around the provided fictional Dr. Maya Reynolds profile.

## Run locally

Requirements: Node.js 18.17+ (Node 20+ recommended).

```bash
npm install
npm run dev
```

Open http://localhost:3000

Production check:

```bash
npm run build
npm start
```

## What is included

- Next.js App Router + TypeScript
- Tailwind CSS theme with reusable CSS variables/colors
- Responsive desktop/tablet/mobile layout
- Homepage structure based on the supplied Conejo Valley Counseling reference
- All homepage copy rewritten from the supplied Dr. Maya Reynolds profile
- SEO metadata focused on Santa Monica, California + anxiety/trauma therapy
- Three profile-based services: Anxiety & Panic, Trauma & EMDR, Burnout & Perfectionism
- Maya portrait and both office images supplied in the profile PDF
- Creative required “Our Office / A Calm Space for Healing” section with office gallery, location and in-person/telehealth details
- FAQ accordion
- Mobile navigation overlay
- Smooth anchor navigation and clear booking CTAs
- Accessible image alt text and semantic section structure

## Notes

The profile identifies Dr. Maya Reynolds as a fictional therapist. The site preserves that framing in the footer/metadata context. The booking CTA is a front-end demo mailto action because the assignment does not provide a real scheduling endpoint.
